---
title: '/housing jumpto'
description: 'Teleports to a player plot'
---

The `jumpto` subcommand teleports you directly to the plot where the specified player is currently located.

## Syntax

```
/housing jumpto [user]
```

## Arguments

### `[user]` (Optional)
The target player name. If omitted, opens a plot search menu.

## Permissions

- `housing.command.jumpto`
