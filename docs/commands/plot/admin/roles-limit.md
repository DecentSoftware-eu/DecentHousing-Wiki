---
title: '/plot admin roles-limit'
description: 'Modifies max roles limit'
---

The `admin roles-limit` subcommand allows administrators to modify or set the plot's maximum roles limit.

## Syntax

```
/plot admin roles-limit add <amount>
/plot admin roles-limit set <value>
```

## Arguments

### `<amount>` (Required in add)
The amount to add to the maximum roles limit.

### `<value>` (Required in set)
The roles limit value to set.

## Permissions

- `housing.command.plot.admin.roleslimit`
