---
title: '/housing plot copy-id'
description: 'Copies a plot ID'
---

The `plot copy-id` subcommand opens a menu allowing you to copy the plot's unique identifier.

## Syntax

```
/housing plot copy-id [--id <id>] [--this]
```

## Arguments

### `[--id <id>]`
The specific ID of the plot to copy.

### `[--this]`
Binds selection to the plot you are currently on.

## Permissions

- `housing.command.plot.copyid`
