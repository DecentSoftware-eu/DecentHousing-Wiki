---
title: '/housing visit'
description: 'Visits another player'
---

The `visit` subcommand allows visiting other players' plots or opening the visit search menu.

## Syntax

```
/housing visit [user]
```

## Arguments

### `[user]` (Optional)
The name of the user whose plots you want to visit. If omitted, opens the visit search menu.

## Permissions

- `housing.command.visit`
