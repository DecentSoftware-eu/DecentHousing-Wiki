---
title: '/plot admin item unlock'
description: 'Unlocks a locked item'
---

The `admin item unlock` subcommand allows administrators to unlock a specific locked item on the plot.

## Syntax

```
/plot admin item unlock <item>
```

## Arguments

### `<item>` (Required)
The key of the locked item to unlock.

## Permissions

- `housing.command.plot.admin.item.unlock`
