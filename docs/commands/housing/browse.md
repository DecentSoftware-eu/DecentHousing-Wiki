---
title: '/housing browse'
description: 'Opens the plot browser'
---

The `browse` subcommand opens a graphical user interface (GUI) menu that allows players to browse available plots on the network.

## Syntax

```
/housing browse [--listingIndex <index>]
```

## Arguments

### `[--listingIndex <index>]` (Optional)
The index of the listing page to open. Alias: `-l`.

## Permissions

- `housing.command.browse`
