---
title: '/plot gm'
description: 'Changes player game mode'
---

The `gm` subcommand changes the Minecraft game mode of the specified player (or yourself if no player is specified).

## Syntax

```
/plot gm <gamemode> [player]
```

## Arguments

### `<gamemode>` (Required)
The game mode to set (e.g., `survival`, `creative`, `adventure`, `spectator`).

### `[player]` (Optional)
The player whose game mode you want to change.
