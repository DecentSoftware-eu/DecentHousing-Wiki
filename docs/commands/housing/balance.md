---
title: '/housing balance'
description: 'Displays player balance'
---

The `balance` subcommand displays the specified player's balance (or your own balance if no player is specified) in a given economy.

## Syntax

```
/housing balance [user] [economy]
```

## Arguments

### `[user]` (Optional)
The player name whose balance you want to check. If omitted, checks your own balance.

### `[economy]` (Optional)
The ID of the economy you want to check. If omitted, checks the default economy.

## Permissions

- `housing.command.balance`
