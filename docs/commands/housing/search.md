---
title: '/housing search'
description: 'Searches plots and players'
---

The `search` subcommand allows players to search for plots or other players. If no query is provided, it opens a search input menu.

## Syntax

```
/housing search [query]
```

## Arguments

### `[query]` (Optional)
The text query to search for. If omitted, opens the search menu.

## Permissions

- `housing.command.search`
