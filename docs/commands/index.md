Welcome to the DecentHousing Commands section. Below is an overview of all the available commands, grouped by category:

### Plot Commands
These commands are used to manage plot settings, player permissions, and administration on the plot server.

- [`/plot menu`](plot/menu.md) - Opens the plot settings menu.
- [`/plot ban`](plot/ban.md) - Bans a player from the plot.
- [`/plot unban`](plot/unban.md) - Unbans a player from the plot.
- [`/plot kick`](plot/kick.md) - Kicks a player from the plot.
- [`/plot mute`](plot/mute.md) - Mutes a player on the plot.
- [`/plot unmute`](plot/unmute.md) - Unmutes a player on the plot.
- [`/plot banlist`](plot/banlist.md) - Displays the plot ban list.
- [`/plot mutelist`](plot/mutelist.md) - Displays the plot mute list.
- [`/plot mutechat`](plot/mutechat.md) - Mutes or unmutes the plot chat.
- [`/plot tp`](plot/tp.md) - Teleports to a player on the plot.
- [`/plot clearinv`](plot/clearinv.md) - Clears a player's inventory.
- [`/plot vote`](plot/vote.md) - Casts a vote for the plot.
- [`/plot gm`](plot/gm.md) - Changes a player's game mode.
- [`/plot spawn`](plot/spawn.md) - Teleports the player to the plot spawn point.
- [`/plot setspawn`](plot/setspawn.md) - Sets the spawn point of the plot.

#### Plot Admin Commands
- [`/plot admin build-area-factor`](plot/admin/build-area-factor.md) - Modifies the build area ratio relative to the original area.
- [`/plot admin player-limit`](plot/admin/player-limit.md) - Adds to or sets the maximum player limit of the plot.
- [`/plot admin roles-limit`](plot/admin/roles-limit.md) - Adds to or sets the maximum roles limit of the plot.
- [`/plot admin item unlock`](plot/admin/item.md) - Unlocks a locked item on the plot.
- [`/plot admin vote`](plot/admin/vote.md) - Forces a vote for the plot.
- [`/plot admin feature activate`](plot/admin/feature.md) - Force-activates a feature on the plot.

### Housing Commands
These are the main housing commands used to browse plots, manage player profiles, check leaderboards, check balances, and perform administrator tasks.

- [`/housing browse`](housing/browse.md) - Opens the plot browser.
- [`/housing search`](housing/search.md) - Searches plots and players.
- [`/housing profile`](housing/profile.md) - Opens a player profile or own plots menu.
- [`/housing visit`](housing/visit.md) - Visits another player.
- [`/housing jumpto`](housing/jumpto.md) - Teleports to a player plot.
- [`/housing myplots`](housing/myplots.md) - Opens your own plots list.
- [`/housing plot join`](housing/plot-join.md) - Joins a plot.
- [`/housing plot copy-id`](housing/plot-copy-id.md) - Copies a plot ID.
- [`/housing callback`](housing/callback.md) - Internal callback executor.
- [`/housing changelog`](housing/changelog.md) - Opens the changelog menu.
- [`/housing dynamic execute`](housing/dynamic.md) - Executes a dynamic command.
- [`/housing top`](housing/top.md) - Opens leaderboards or lists top players.
- [`/housing hub`](housing/hub.md) - Sends you to the hub server.
- [`/housing balance`](housing/balance.md) - Displays player balance.
- [`/housing pay`](housing/pay.md) - Sends funds to a player.

#### Housing Admin Commands
- [`/housing admin user`](housing/admin/user.md) - User administration commands.
- [`/housing admin package`](housing/admin/package.md) - Premium package administration.
- [`/housing admin plot`](housing/admin/plot.md) - Plot administration.
- [`/housing admin economy`](housing/admin/economy.md) - Economy administration.
- [`/housing admin tags`](housing/admin/tags.md) - Tag administration.
- [`/housing admin reload config`](housing/admin/reload.md) - Reloads the configuration.
