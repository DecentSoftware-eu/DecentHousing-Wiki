This section contains additional documentation, general reference materials, and standardized conventions used across DecentHousing.

### Config Conventions

Standardized configuration structures shared across different features and configuration files:

- **[Price](config-conventions/price.md)**  
  Standardized configuration syntax for defining purchasing costs, economies, and free offers across features, items, and menus.
- **[Item Selector](config-conventions/item-selector.md)**  
  Standardized configuration syntax for matching in-game items by material, custom resource pack models (CustomModelData), and item tags.
- **[Item](config-conventions/item.md)**  
  Standardized configuration syntax for custom items, their visual appearance, price, locking rules, selectors, and interactive actions.
- **[Action](config-conventions/action.md)**  
  Standardized configuration syntax for automated commands, chat messages, and operations triggered by player interactions and plot events.
