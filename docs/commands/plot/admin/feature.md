---
title: '/plot admin feature activate'
description: 'Force activates a feature'
---

The `admin feature activate` subcommand allows administrators to force the activation of a feature on the plot.

## Syntax

```
/plot admin feature activate <feature>
```

## Arguments

### `<feature>` (Required)
The key of the feature to activate.

## Permissions

- `housing.command.plot.admin.feature.activate`
