---
title: '/plot admin player-limit'
description: 'Modifies max player limit'
---

The `admin player-limit` subcommand allows administrators to modify or set the plot's maximum player limit.

## Syntax

```
/plot admin player-limit add <amount>
/plot admin player-limit set <value>
```

## Arguments

### `<amount>` (Required in add)
The amount to add to the maximum player limit.

### `<value>` (Required in set)
The player limit value to set.

## Permissions

- `housing.command.plot.admin.playerlimit`
