---
title: '/housing dynamic execute'
description: 'Executes a dynamic command'
---

The `dynamic execute` subcommand invokes a registered dynamic command with arguments.

## Syntax

```
/housing dynamic execute <name> [args]
```

## Arguments

### `<name>` (Required)
The name of the dynamic command to execute.

### `[args]` (Optional)
The list of arguments to pass to the dynamic command.

## Permissions

- None (Subject to internal dynamic command registry permissions)
