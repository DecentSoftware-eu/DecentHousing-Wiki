---
title: '/housing top'
description: 'Opens leaderboards or lists top players'
---

The `top` subcommand opens the main leaderboards menu or prints leaderboard pages (richest players, top creators) in chat.

## Syntax

```
/housing top
/housing top richest [page] [economy]
/housing top creators [page]
```

## Arguments

### `[page]` (Optional, defaults to 1)
The page number of the leaderboard to display.

### `[economy]` (Optional)
The economy ID for the richest leaderboard. If omitted, uses the default economy.

## Permissions

- `housing.command.top`
