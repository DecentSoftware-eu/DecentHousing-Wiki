---
title: '/housing profile'
description: 'Opens a player profile or own plots menu'
---

The `profile` subcommand opens a GUI profile menu for the specified player or yourself.

## Syntax

```
/housing profile [user]
```

## Arguments

### `[user]` (Optional)
The name of the user whose profile you want to open. If omitted, opens your own profile.

## Permissions

- `housing.command.profile`
